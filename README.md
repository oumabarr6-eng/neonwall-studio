# NeonWall Studio — TikTok Wallpaper & Video 4K Cleaner

SaaS cyber-futuriste : photos & vidéos TikTok → wallpapers **4K Ultra-HD sans filigrane** + vidéos clean.

## Deploy sur Netlify

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/oumabarr6-eng/neonwall-studio)

1. Clique le bouton ci-dessus
2. Connecte ton compte Netlify / GitHub
3. Deploy — `netlify.toml` configure automatiquement Next.js

## Deploy sur Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/oumabarr6-eng/neonwall-studio)

## Local

```bash
npm install
npm run dev
```

## Stack

- Next.js 15 (App Router) + Tailwind CSS v4
- Framer Motion + Lucide + Sharp

## Fonctionnalités

- Photo & Vidéo TikTok (démo)
- Upscale 4K + purge metadata
- Filtres néon + Roulette trending
- Export WebP / vidéo clean
