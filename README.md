# NeonWall Studio — TikTok Wallpaper & Video 4K Cleaner

SaaS cyber-futuriste pour transformer des **photos et vidéos TikTok** en wallpapers **4K Ultra-HD sans filigrane** + vidéos clean.

## Stack

- Next.js 15 (App Router)
- Tailwind CSS v4
- Framer Motion + Lucide React
- Sharp (upscale + metadata purge)

## Run

```bash
npm install
npm run dev
```
